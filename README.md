# 🌿 EcoSight

> AI 기반 환경 모니터링 및 시각화 플랫폼

EcoSight는 환경 데이터를 실시간으로 모니터링하고 시각화하여 보다 직관적인 인사이트를 제공하는 웹 애플리케이션입니다.

## 🚀 주요 기능
- **실시간 데이터 시각화**: 주요 환경 지표 분석 및 차트 제공
- **AI 기반 분석**: 데이터 트렌드 예측 및 이상 징후 감지
- **사용자 친화적 UI**: 직관적인 대시보드 인터페이스

## 🛠️ 기술 스택
- **Frontend**: TypeScript, React, Vite
- **Backend / Server**: Node.js, TypeScript
